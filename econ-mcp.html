Econ Data — an MCP server for economics.

An assistant that can reach this server stops guessing at economic numbers. It pulls the series from the statistical office that publishes it, runs the test the data actually supports, and hands back the survey break and the index-not-quantity warning in the same reply. Any MCP client can connect: Claude, Claude Code, Cursor, or your own agent.

The server is open today. It carries a bearer-token check for the day access needs to be limited, and nothing about a connection is stored: no query log, no series cache beyond ten minutes inside the worker.

What it serves

Two kinds of data, deliberately. Curated datasets live in this repository, are rebuilt by a scheduled pipeline, and carry the notes I attach to them. Live providers are far too large to copy, so the server fetches from them on demand and stores nothing.

The toolkit

Every analysis tool takes the same kind of reference, so one call works on a curated dataset, a live pull, or numbers pasted in by hand.

{ "dataset": "us-prices", "series": "cattle_ppi", "transform": "log", "start": "1990-01" }
{ "provider": "imf", "id": "IMF.RES/WEO/TUR.NGDP_RPCH.A" }
{ "provider": "eurostat", "id": "prc_hicp_midx", "params": { "geo": "TR", "coicop": "CP00" } }
{ "points": [["2020", 101.2], ["2021", 104.9]], "label": "mine" }
ToolWhat it answers
suggest_analysisWhich method does this data actually support? Checks frequency, length, integration order, seasonality, volatility clustering and overlap, then returns an ordered plan with the pitfalls named. The place to start.
describe_statsMoments, autocorrelation, normality, unit roots, trend and seasonal strength.
test_stationarityAugmented Dickey-Fuller and KPSS together, with a joint reading rather than one test's verdict.
regressOLS with Newey-West errors, distributed lags, residual tests, and a warning when a levels regression looks spurious.
iv_regressIs the relation causal? Two-stage least squares with an instrument, next to OLS, with the tests that say whether the instrument is strong and whether OLS was biased at all.
quantile_regressDoes the relation hold in the tails, or only on average?
panel_regressDoes it hold across countries? Within, pooled and between estimates side by side, errors clustered by country.
cointegration, johansen, vecmIs there a long-run relation, how many, which series corrects the deviation, and how far from equilibrium the system sits right now.
granger_causality, cross_correlationWhich one moves first, and by how many periods.
var_modelHow a shock to one series propagates to the others, with variance decomposition.
local_projectionsThe same impulse response one horizon at a time, with a confidence band on each, and no lag structure imposed.
volatilityDoes variance cluster, how persistent is a shock, and is the current volatility above or below normal.
principal_componentsIs there one common factor behind these series, and what loads on it.
forecast_evaluateWhich method actually forecasts this series? Every method re-fitted at past origins and scored on what came next, against a naive no-change forecast.
forecastHolt-Winters, Holt, AR or ARIMA with the order chosen by AIC, dated, with a band.
structural_break, rollingDid the relationship change, when, and how many times — with proper sup-F critical values, before anyone quotes a single number for the whole sample.
hp_filter, decompose, deflateTrend and cycle, seasonal factors, and nominal series put into constant prices.
plotDraws up to eight series and returns a link to an interactive chart that redraws from fresh data every time it is opened; forecasts and impulse responses come with their band drawn.

What it will not do

It will not hand back a number without saying where the number came from. Every result carries the source and the caveats the dataset travels with — the rebased index, the survey break, the figure that is an index and not a quantity, the country-year the statistical office imputed. That is the whole point of putting the data behind a server instead of letting a model recall it: a recalled number has no provenance, and no way to be wrong out loud.

Built as a Cloudflare Worker with no runtime dependencies beyond the MCP SDK; the curated data is refreshed by a scheduled pipeline in the same repository, so a data refresh needs no redeploy. Source and full tool reference: github.com/namikakmandev · the dataset catalogue · the chart page
