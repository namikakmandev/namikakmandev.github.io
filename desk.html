AH Data Desk

One live indicator layer. Every series carries its source, its exact dataset code, its deflator, its known breaks, and — the part that is normally missing — what it does not measure. Ask a question and the answer arrives with those attached.

Scope of this demo: built entirely from public sources — Eurostat, FAOSTAT, USDA ERS, BLS/FRED, TÜİK/TEPGE — refreshed by the existing GitHub Actions pipeline. No company, customer or licensed market data is used here, and none should be added to this repository. Internal sources belong in a company-approved private environment; this page is the pattern, not the destination.

How this extends to internal data

Nothing on this page is bespoke. scripts/build_desk.py reads whatever series exist and emits one desk-index.json; the page renders that file. Adding a series to the public pipeline is a single entry in data-sources.json — no new code:

{ "name": "eu-vet-countries", "provider": "eurostat",
  "dataset": "aact_eaa01",
  "params": { "am_item": "AM205000", "unit": "MIO_EUR", "geo": ["FR","DE","PL", "..."] },
  "out": "data/eu-vet-countries.json",
  "note": "all livestock, not cattle only" }

Pointing this at internal or licensed sources means adding a provider that reads from the approved warehouse and running it inside the company environment. The page, the indicator contract and the caveat discipline stay exactly as they are.

Two things to settle before any of that happens: whether the licence for each paid source permits internal redistribution and ingestion into an AI system, and which approved service the question layer is allowed to call. The answer layer below is deliberately deterministic — it answers only from the indicator file and says so plainly when it cannot, which is the behaviour any LLM sitting in its place would need to be held to.
