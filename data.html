The data behind the studies.

Every study on this site is built from public statistics pulled by a small pipeline in the same repository. This is the index of that data: what produced each file, what it covers, how fresh it is — and, honestly, which files can no longer account for themselves. Generated by scripts/build_catalog.py, not maintained by hand.

Loading the catalogue…

What provenance means. Pipeline — fetched by scripts/fetch.py from a definition in data-sources.json and refreshed on a schedule; adding one is a few lines of config, not a new script. Script — written by another script in scripts/, run by hand, so it is only as current as its last run. Manual — pulled by hand from a source the pipeline cannot reach, carrying an explicit as-of date because it cannot refresh itself. Unattributed — nothing in the repository writes it. Those are exploratory files left behind; they are listed rather than deleted so the gap is visible, and nothing published depends on them.

Why this exists. The directory grew to forty-odd files across a dozen different shapes, written by several scripts at different times. Starting a new study meant opening old files to work out what was there. One generated index is cheaper than that, and it makes staleness visible instead of leaving it to be discovered later.
